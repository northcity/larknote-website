# 云雀记 LarkNote 官网

独立的静态官网。GitHub Pages 来源：main 分支根目录。

自定义域名：yunqueji.com（DNS 在阿里云）。根域名 A 记录指向 GitHub Pages 的 185.199.108.153 / 109 / 110 / 111；`www` CNAME 指向 northcity.github.io，由 GitHub 自动跳转到根域名。

法律页面：`terms.html`（使用条款）、`privacy.html`（隐私政策），共用 `legal.css`。App 内 `AppSupportLinks` 指向 `https://yunqueji.com/terms.html` 与 `https://yunqueji.com/privacy.html`，改名或移动需同步修改 App；隐私政策内容需与 App 内隐私说明一致。

不修改 northcity.github.io、anpa-website、ideasnap-web 或其他官网仓库。
